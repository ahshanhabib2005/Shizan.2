পূর্ববর্তী পেজে ফিরে যান

Advanced Gas Leakage Detection & Automated Mitigation System

১. প্রজেক্টের সারসংক্ষেপ (Abstract)

বর্তমান শিল্পায়ন ও আধুনিক গৃহস্থালিতে এলপিজি (LPG), মিথেন এবং অন্যান্য দাহ্য গ্যাসের ব্যবহার বহুলভাবে বৃদ্ধি পেয়েছে। তবে অসাবধানতা বা যান্ত্রিক ত্রুটির কারণে গ্যাস লিকেজ হয়ে ভয়াবহ অগ্নিকাণ্ড, বিস্ফোরণ ও প্রাণহানির ঝুঁকি তৈরি হয়। এই গবেষণামূলক প্রজেক্টে একটি আধুনিক, স্বয়ংক্রিয় ও নির্ভরযোগ্য "Advanced Gas Leakage Detection and Automated Mitigation System" ডিজাইন ও বাস্তবায়ন করা হয়েছে।

সিস্টেমটি বাতাসের গুণমান এবং দাহ্য গ্যাসের ঘনত্ব (PPM - Parts Per Million) রিয়েল-টাইমে পর্যবেক্ষণ করে। কোনো এলাকায় গ্যাসের পরিমাণ বিপদসীমা অতিক্রম করলে সিস্টেমটি তাৎক্ষণিকভাবে স্থানীয়ভাবে হাই-ডেসিবল বুজার (Buzzer) অ্যালার্ম বাজায়, GSM মডিউলের মাধ্যমে দায়িত্বপ্রাপ্ত ব্যক্তির মোবাইলে কাস্টমাইজড SMS বার্তা পাঠায় এবং ইলেকট্রোমেকানিক্যাল রিলে মডিউলের মাধ্যমে এক্সহস্ট ফ্যান চালু করে বাতাস থেকে গ্যাস বের করে দেয়। এটি একটি সম্পূর্ণ অটোমেটেড সেফটি নেটওয়ার্ক প্রদান করে।

২. ভূমিকা ও পটভূমি (Introduction & Background)

গ্যাস লিকেজজনিত দুর্ঘটনা বর্তমানে বিশ্বব্যাপী একটি বড় উদ্বেগ। বিশেষ করে গৃহস্থালির রান্নাঘর, রেস্তোরাঁ, সিএনজি ফিলিং স্টেশন, মেটাল প্রসেসিং ইন্ডাস্ট্রি এবং রাসায়নিক কারখানায় দাহ্য গ্যাস অত্যন্ত বিপজ্জনক অবস্থায় থাকে। এলপিজি প্রধানত প্রোপেন ($C_3H_8$) এবং বিউটেন ($C_4H_{10}$)-এর মিশ্রণ, যা বাতাসের চেয়ে ভারী হওয়ায় লিকেজ হলে মেঝের কাছাকাছি জমা হতে থাকে এবং সামান্য বৈদ্যুতিক স্পার্কের সংযোগ পেলেই বিশাল বিস্ফোরণ ঘটায়।

সনাতন পদ্ধতিতে মানুষ কেবল গন্ধ পেয়ে গ্যাস লিকেজ শনাক্ত করতে পারে, যা অনেক সময় ঘুমের মধ্যে বা অবর্তমানে সম্ভব হয় না। এই সমস্যা সমাধানে এমবেডেড সিস্টেম (Embedded Systems) এবং ইন্টারনেট অব থিংস (IoT) প্রযুক্তির সমন্বয়ে এই প্রজেক্টটি তৈরি করা হয়েছে, যা মানুষের উপস্থিতি ছাড়াই ২৪/৭ নিরবচ্ছিন্ন নিরাপত্তা সুনিশ্চিত করে।

৩. সেন্সর প্রযুক্তির বিস্তারিত ইতিহাস (History of Gas Sensor Technology)

ইন্ডাস্ট্রিয়াল সেফটি ও প্রযুক্তি বিবর্তনের ইতিহাস বিশ্লেষণ করলে দেখা যায়, আদি যুগে কয়লা খনিতে মিথেন বা বিষাক্ত কার্বন মনোক্সাইড শনাক্ত করার জন্য খনি শ্রমিকরা খাঁচায় বন্দী 'ক্যানারি পাখি' (Canary Birds) সাথে নিয়ে যেত। বাতাসে বিষাক্ত গ্যাসের উপস্থিতি ঘটলে সংবেদনশীল পাখিটি প্রথমে অসুস্থ বা মারা যেত, যা শ্রমিকদের খনি খালি করার সতর্কবার্তা দিত।

১৯৫২ সালে ডেনিস হ্যারিয়ট প্রথম মেটাল অক্সাইড সেমিকন্ডাক্টর (MOS) গ্যাসের প্রাথমিক নীতি আবিষ্কার করেন। পরবর্তীতে ১৯৬২ সালে জাপানি গবেষক নাভোশি তাগুচি (Naoyoshi Taguchi) প্রথম কমার্শিয়াল টিন ডাই-অক্সাইড ($SnO_2$) ভিত্তিক সেমিকন্ডাক্টর গ্যাস সেন্সর পেটেন্ট করেন। যখন গরম টিন ডাই-অক্সাইড সারফেস রিডিউসিং গ্যাসের (যেমন LPG বা CO) সংস্পর্শে আসে, তখন এর ইলেকট্রন ডেনসিটি বৃদ্ধি পায় এবং সারফেস রেজিস্ট্যান্স আশঙ্কাজনকভাবে হ্রাস পায়। এই উদ্ভাবনের ওপর ভিত্তি করেই আধুনিক MQ সিরিজের গ্যাস সেন্সরগুলো विकसित হয়েছে।

৪. প্রজেক্টের মূল উদ্দেশ্যসমূহ (Objectives)

  • রিয়েল-টাইম গ্যাস মনিটরিং: বাতাসের গ্যাসের ঘনত্ব সার্বক্ষণিক সুনির্দিষ্টভাবে পরিমাপ করা।
  • বহুমাত্রিক অ্যালার্ট সিস্টেম: গ্যাস লিকেজ হওয়া মাত্র অডিও অ্যালার্ম (Buzzer) এবং রিমোট মোবাইল নোটিফিকেশন (SMS) প্রদান।
  • অটোমেটেড প্রতিরোধ ব্যবস্থা: রিলে সুইচিংয়ের মাধ্যমে এক্সহস্ট ফ্যান ট্রিগার করে দ্রুত গ্যাস অপসারণ করা।
  • ফলস অ্যালার্ম প্রতিরোধ: সঠিক ক্যালিব্রেশন এবং সফটওয়্যার থ্রেশহোল্ডিং প্রয়োগের মাধ্যমে মিথ্যা অ্যালার্ম কমিয়ে আনা।

৫. সিস্টেম আর্কিটেকচার (System Architecture & Block Diagram)

পুরো প্রজেক্টটি একটি ক্লোজড-লুপ কন্ট্রোল সিস্টেমের মতো কাজ করে। এটি প্রধানত ৪টি মূল স্তরে বিভক্ত:

  • সেন্সিং লেয়ার (Sensing Layer): MQ-2 Gas Sensor কেমিক্যাল পরিবর্তনকে ইলেকট্রিক্যাল ভোল্টেজে রূপান্তর করে।
  • প্রসেসিং লেয়ার (Processing Layer): ESP32 Microcontroller সেন্সরের অ্যানালগ ডাটা প্রসেস করে সিদ্ধান্ত গ্রহণ করে।
  • কমিউনিকেশন লেয়ার (Communication Layer): SIM800L GSM Module সেলুলার নেটওয়ার্ক ব্যবহার করে কাস্টমাইজড বার্তা পাঠায়।
  • একচুয়েশন লেয়ার (Actuation Layer): 5V Relay Module, Buzzer এবং Exhaust Fan শারীরিক প্রতিরোধ মূলক ব্যবস্থা গ্রহণ করে।

৬. প্রয়োজনীয় হার্ডওয়্যার ও যন্ত্রাংশের বিবরণ (Hardware Description)

১. ESP32 ডেভলপমেন্ট বোর্ড

বিবরণ: এটি প্রজেক্টের মূল মস্তিষ্ক। এতে রয়েছে Tensilica Xtensa Dual-Core 32-bit প্রসেসর, যা ২৪০ মেগাহার্টজ স্পিডে কাজ করে। এর ১২-বিট এনালগ-টু-ডিজিটাল কনভার্টার (ADC) সেন্সরের ডাটা নিখুঁতভাবে বিশ্লেষণ করে।

২. MQ-2 গ্যাস সেন্সর

বিবরণ: এটি একটি মেটাল অক্সাইড সেমিকন্ডাক্টর (MOS) সেন্সর। এটি ৩০০ PPM থেকে ১০,০০০ PPM রেঞ্জে LPG, আইসো-বিউটেন, প্রোপেন, মিথেন, অ্যালকোহল ও ধোঁয়ার উপস্থিতি পরিমাপ করতে পারে।

৩. SIM800L GSM মডিউল

বিবরণ: এটি একটি ছোট আকৃতির সেলুলার মডিউল যা Quad-band (850/900/1800/1900MHz) সাপোর্ট করে। UART সিগন্যাল ও AT Command-এর মাধ্যমে এটি প্রসেসরের নির্দেশে সরাসরি SMS পাঠায়।

৪. ৫ ভোল্ট রিলে মডিউল

বিবরণ: এটি অপটোকাপলার যুক্ত একটি ড্রাইভার সার্কিট। কম ভোল্টেজের মাইক্রোকন্ট্রোলারের মাধ্যমে উচ্চ ভোল্টেজের এক্সহস্ট ফ্যান বা সোলোনয়েড ভালভ নিরাপদে নিয়ন্ত্রণ করতে এটি কাজ করে।

৫. এক্সহস্ট ফ্যান, বুজার ও পাওয়ার সাপ্লাই

বিবরণ: নিরাপত্তা নিশ্চিত করতে ফ্যান বাতাস বের করে দেয়, ৯৫dB বুজার শব্দ করে বিপদ জানায় এবং একটি Buck Converter স্থায়ী বিদ্যুৎ সরবরাহ নিশ্চিত করে।

৭. কাজের পদ্ধতি ও কার্যপ্রণালী (Working Principle)

  1. হিটিং ও প্রিপারেশন: MQ-2 সেন্সরের অভ্যন্তরীণ ইন্টারনাল হিটার (Internal Heater) হিটিং কয়েলকে উত্তপ্ত করে সেন্সিং কেমিক্যাল সক্রিয় করে।
  2. ডাটা একুইজিশন: সেন্সর থেকে অ্যানালগ ভোল্টেজ সিগন্যাল ESP32-এর GPIO36 (ADC1_CH0) পিনে আসে। ADC ভোল্টেজকে ০ থেকে ৪০৯৫ ডিজিটাল মানদণ্ডে পরিবর্তন করে।
  3. থ্রেশহোল্ড চেক: প্রোগ্রাম কোডে আগে থেকেই একটি নিরাপত্তা সীমা (যেমন:১৮০০ ডিজিট বা ৩০০ PPM) সেট করা থাকে। প্রসেসর ক্রমাগত বর্তমান রিডিং পরীক্ষা করে।
  4. ট্রিপিং ও একচুয়েশন: যদি সেন্সর ভ্যালু থ্রেশহোল্ড অতিক্রম করে, তবে প্রসেসর ডিজিটাল পিন হাই (HIGH) করে দিলে রিলে চালু হয়ে ফ্যান ও বুজার অন হয়।
  5. মেসেজিং সাবসিস্টেম: একই সময়ে Hardware Serial2 ব্যবহার করে SIM800L কে AT Command (AT+CMGS) পাঠায় এবং ব্যবহারকারীর ফোনে জরুরি বার্তা ডেলিভারি হয়।

৮. সার্কিট ডায়াগ্রাম ও পুঙ্খানুপুঙ্খ কানেকশন বিবরণ (Circuit Connections)

সিস্টেমের বিভিন্ন মডিউলের মধ্যে সঠিক কানেকশন ছক নিচে তুলে ধরা হলো:

মডিউলের নাম মডিউল পিন ESP32 পিন / পাওয়ার সাপ্লাই
MQ-2 Sensor VCC / GND / AOUT 5V / GND / GPIO 36 (VP)
SIM800L GSM VCC / GND / TXD / RXD 4.0V Buck Output / GND / GPIO 16 (RX2) / GPIO 17 (TX2)
5V Relay Module VCC / GND / IN 5V / GND / GPIO 25
Piezo Buzzer Positive (+) / Negative (-) GPIO 26 / GND

৯. প্রজেক্টের সোর্স কোড (Source Code - Embedded C/C++)

Arduino IDE ব্যবহার করে ESP32 বোর্ডের জন্য ডেভেলপ করা সোর্স কোড:

#include <HardwareSerial.h>

// পিন কনফিগারেশন
const int gasSensorPin = 36; // MQ-2 Analog Pin (GPIO 36)
const int buzzerPin = 26;    // Buzzer Pin
const int relayPin = 25;     // Relay Pin
const int threshold = 1800;  // বিপদসীমা (ADC Value)

// SIM800L এর জন্য Hardware Serial 2 নির্ধারণ
HardwareSerial sim800(2);

bool smsSent = false;

void setup() {
  Serial.begin(115200);
  
  // ESP32 Hardware Serial2: RX=16, TX=17
  sim800.begin(9600, SERIAL_8N1, 16, 17);

  pinMode(gasSensorPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(relayPin, OUTPUT);

  digitalWrite(buzzerPin, LOW);
  digitalWrite(relayPin, LOW);

  Serial.println("System Initializing... Pre-heating Sensor...");
  delay(10000); // প্রাথমিক ওয়ার্ম-আপ সময়
}

void loop() {
  int sensorValue = analogRead(gasSensorPin);
  Serial.print("Gas Sensor ADC Value: ");
  Serial.println(sensorValue);

  if (sensorValue > threshold) {
    // বিপদকালীন অবস্থা
    digitalWrite(buzzerPin, HIGH);
    digitalWrite(relayPin, HIGH); // ফ্যান চালু
    
    if (!smsSent) {
      sendEmergencySMS(sensorValue);
      smsSent = true;
    }
  } else {
    // স্বাভাবিক অবস্থা
    digitalWrite(buzzerPin, LOW);
    digitalWrite(relayPin, LOW);
    smsSent = false; // রিসেট
  }
  
  delay(1000);
}

void sendEmergencySMS(int val) {
  Serial.println("Sending Emergency SMS via SIM800L...");
  sim800.println("AT+CMGF=1"); // SMS টেক্সট মোড
  delay(1000);
  
  sim800.println("AT+CMGS=\"+8801590059760\""); // প্রাপকের মোবাইল নম্বর
  delay(1000);
  
  sim800.print("EMERGENCY ALERT: High Gas Leakage Detected! Sensor Level: ");
  sim800.print(val);
  sim800.print(". Exhaust Fan Activated.");
  delay(500);
  
  sim800.write(26); // Ctrl+Z কমান্ড পাঠানো

}

১০. গাণিতিক ফর্মুলা ও ক্যালিব্রেশন (Mathematical Analysis)

MQ-2 সেন্সরের সারফেস রেজিস্ট্যান্স ($R_s$) এবং গ্যাসের ঘনত্বের (PPM) সম্পর্ক একটি লগারিদমিক সমীকরণ মেনে চলে:

$$R_s = \left( \frac{V_{in} - V_{out}}{V_{out}} \right) \times R_L$$

যেখানে $V_{in}$ হলো ইনপুট ভোল্টেজ (5V), $V_{out}$ হলো সেন্সরের অ্যানালগ আউটপুট ভোল্টেজ এবং $R_L$ হলো লোড রেজিস্ট্যান্স (10kΩ)। পরিষ্কার বাতাসে সংগৃহীত রেজিস্ট্যান্সের মানকে $R_0$ ধরা হয়। ডাটাশিট অনুযায়ী $\frac{R_s}{R_0}$ অনুপাত নির্ণয় করে নিখুঁত PPM গণনা করা হয়।
